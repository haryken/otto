Mức giảng bài

Chọn cách robot dạy khi bé học thẻ
  • Ít ĐANG CHỌN Robot đọc từ / câu tiếng Anh rồi kêu bé nhắc lại. Giảng rất ít hoặc không giảng nghĩa. Đang chọn mức Ít: robot luyện nói, không đưa bản giải thích basic/detailed.
  • Cơ bản ĐANG CHỌN Robot giảng nghĩa ngắn (tiếng Việt + tiếng Anh) rồi mới kêu bé nói. Không đi sâu ví dụ hay lúc nào dùng câu đó. Đang chọn mức này: robot dạy nghĩa nhanh rồi luyện nói. Hợp lần đầu học từ mới, cần hiểu rồi nhắc lại.
  • Chi tiết ĐANG CHỌN Robot giảng kỹ: nghĩa, ví dụ, lúc nào dùng câu đó, rồi mới luyện nói. Giống giáo viên giải thích trước khi kêu bé nói. Đang chọn mức này: robot nhận bản giải thích đầy đủ của bài học. Hợp khi bé cần hiểu sâu, hoặc phụ huynh muốn dạy kỹ.

    Cập nhật thủ công

    🛠️ Dành cho người tự build firmware

    Chọn một trong hai cách bên dưới. Chỉ dùng file xiaozhi.bin (trong thư mục build/), không dùng merged-binary.bin.

    1. Lấy file xiaozhi.bin trong thư mục build/ sau khi build.
    2. Bấm Chọn file bên dưới và chọn file đó.
    3. Bấm 📤 Tải lên và cập nhật.
    4. Giữ trang này mở đến khi thanh tiến trình chạy xong.
    1. Dán link tải trực tiếp tới file .bin (bắt đầu bằng http:// hoặc https://).
    2. Bấm ⬇️ Cập nhật từ link.
    3. Robot tự tải file về và cài, bạn có thể đóng trang.

    🤖 Chế độ trò chuyện

    Tab này chỉ cho Tiếng Anh cũ (World Edu / giao tiếp cũ). Kiểu mới không dùng tab này — Gemini/Xiaozhi mới nằm tab Học nói và Giao tiếp hằng ngày.

    Xiaozhi: dùng máy chủ Xiaozhi như cũ. OpenAI / Grok / Gemini: robot nói chuyện thẳng với AI bằng API key của bạn, không qua máy chủ trung gian (phí tính vào tài khoản API của bạn).

    Đổi giữa Xiaozhi và AI trực tiếp thì robot tự khởi động lại. Đổi giữa các AI với nhau thì áp dụng từ lần trò chuyện sau.
