    Cập nhật thủ công

    🛠️ Dành cho người tự build firmware

    Chọn một trong hai cách bên dưới. Chỉ dùng file xiaozhi.bin (trong thư mục build/), không dùng merged-binary.bin.

    1. Lấy file xiaozhi.bin trong thư mục build/ sau khi build.
    2. Bấm Chọn file bên dưới và chọn file đó.
    3. Bấm 📤 Tải lên và cập nhật.
    4. Giữ trang này mở đến khi thanh tiến trình chạy xong.
    1. Dán link tải trực tiếp tới file .bin (bắt đầu bằng http:// hoặc https://).
    2. Bấm ⬇️ Cập nhật từ link.
    3. Robot tự tải file về và cài, bạn có thể đóng trang.

    🤖 Chế độ trò chuyện

    Xiaozhi: dùng máy chủ Xiaozhi như cũ. OpenAI / Grok / Gemini: robot nói chuyện thẳng với AI bằng API key của bạn, không qua máy chủ trung gian (phí tính vào tài khoản API của bạn).

    Đổi giữa Xiaozhi và AI trực tiếp thì robot tự khởi động lại. Đổi giữa các AI với nhau thì áp dụng từ lần trò chuyện sau.
